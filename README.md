# KCL Printing & Photocopy Shop

**Live site:** Not deployed yet

**GitHub repository:** https://github.com/c20245709lozano-debug/midterm-printing-shop

## About

KCL Printing & Photocopy Shop is a responsive website designed to introduce the shop's printing, photocopying, and document services. It provides customers with a simple way to explore the business, learn about its services, and find contact information.

## Design System

### Palette (60-30-10)

| Role | Share | Color | Used for |
|---|---|---|---|
| Dominant | 60% | `#DCEBFA` | Main page background and primary sections |
| Secondary | 30% | `#F8DDE8` | Service sections, cards, and visual grouping |
| Accent | 10% | `#FFF0B8` | Highlights, accent elements, and footer |

### Visual style

**Style chosen:** Minimalism with a soft pastel aesthetic.

**Why I chose it:** I chose this style to create a clean, welcoming, and organized website that makes the shop's information easy to read and navigate.

### Contrast check

Body text color vs. background color: `#34495E` on `#DCEBFA`

Contrast ratio: 7.66 : 1 (needs to be at least 4.5 : 1)

Tool used: WebAIM Contrast Checker

## Features

- [x] Mobile-first responsive layout
- [x] Dark mode toggle
- [x] Page-load intro animation (GSAP timeline)
- [x] Scroll reveals on every section below the hero (ScrollTrigger)
- [x] Scroll progress bar (scrub)
- [x] Reduced-motion support

## Built With

HTML, Tailwind CSS v4, JavaScript, GSAP 3.13.0, ScrollTrigger 3.13.0
